# Artwork And Licensing

Notesy source code and project-created artwork are distributed under the GNU
General Public License, version 3 or (at your option) any later version
(SPDX: GPL-3.0-or-later). The complete license is in the root LICENSE file.

- `packaging/notesy.svg`: original Notesy desktop icon.
- `src/main/resources/org/stickynotefx/icons/notesy-*.png`: raster versions of
  that icon, generated by `scripts/GenerateVisualAssets.java` using JDK Java2D.
- `src/main/resources/org/stickynotefx/paper-texture.png`: deterministic
  project-generated texture from the same script.
- `src/main/java/org/stickynotefx/ui/playful/`: original egg, bomb and toaster
  vector artwork implemented as JavaFX shapes, not downloaded asset packs.
- `docs/screenshots/*.png`: captures of the project's UI from the native UI
  tests. The standard reminder image combines two captures of that UI.

There are no bundled fonts or third-party stock images. Installed fonts are
selected at runtime. The JDK and JavaFX are build/runtime dependencies, not
vendored artwork or binaries. AppStream metadata is separately offered under
CC0-1.0, as declared by its metadata_license element.

Screenshot publication uses the canonical repository's `main/docs/screenshots`
paths listed in AppStream. Keep those files publicly available when publishing
the release; local metadata validation does not verify their online availability.
